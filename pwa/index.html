            Android での使い方

            1. app を入れる（最初の1回）

            1. Android の Chrome でこのページを開く（Mac の paper_reader の「スマホ」に出る QR を読むと開けます）。
            2. 右上の ︙ →「ホーム画面に追加」または「アプリをインストール」。
            3. ホーム画面の paper_reader から開く。以後は電波がなくても動きます。

            2. 論文と単語帳を写す（Mac → スマホ）

            1. Mac の paper_reader で「スマホ」→ 送る論文を選んで「Wi‑Fi でスマホに送る」。
            2. スマホを Mac と同じ Wi‑Fi につなぎ、Mac に出た QR をカメラで読む。
            3. 開いた画面の「データを保存」で zip を保存（「ダウンロード」に入ります）。
            4. この app の「データ」→「zip を選ぶ」で、保存した zip を選ぶ。

            Wi‑Fi が使えないときは、Mac の「ファイルで渡す」で zip を保存し、Google Drive や USB でスマホに移してから同じように選びます。

            3. 聞く

            • 「読む」で論文を選び、章の ▶ でその章、「全体を読む」で最初から。「文を見る」を開くと、各文の ▶ でその1文だけ再生できます。
            • 下の再生バー: 一番上の棒が再生している範囲（章・全体・1文）の進み具合です。動かすとその位置へ飛びます。
            • −10 / −5 / +5 / +10 で秒単位に戻す・進める（文をまたいでも続きます）、⏮ ⏭ で前後の文、右で速さ。
            • 画面を消しても続きます。ロック画面や通知から一時停止・次の文へ進めます。
            • Mac で作った日本語訳があれば、各文の下に出ます（「訳」で表示・非表示）。
            • 論文の上の「図・表・数式」で一覧が出ます。押すと大きく開き、左右にはらうと前後の図。「画像を開く・保存」で画像そのものを開けます。
            • 文の中の単語をタップすると辞書が出ます。覚えたい単語は「単語帳に登録」を押すと単語帳に入り、復習に出ます。

            4. 復習する

            • 「復習」で単語と、それを引いた論文の文が出ます。意味を思い出してから「答えを見る」。
            • 思い出せた度合いで4つから選ぶ。もう一度＝思い出せない、難しい＝なんとか、正解＝少し考えて（迷ったらこれ）、簡単＝すぐ。
            • ボタンの下の時間は、次にその単語が出るまでの間隔です（FSRS。Anki と同じ方式）。新しい単語は1日20語まで。

            5. 記録を Mac に戻す（スマホ → Mac）

            1. 「データ」→「記録を書き出す」。共有の画面が出たら Google Drive などに保存、出なければ「ダウンロード」に保存されます。
            2. Mac で「Wi‑Fi でスマホに送る」を開いているなら、スマホでその画面の「記録を Mac に送る」で送れます。 または、ファイルを Mac に移して paper_reader の「スマホ」→「記録ファイルを読み込む」。
            3. Mac とスマホのどちらで復習しても、答えた時刻の順に計算し直して合わせます。

            データの置き場所

            論文・音声・単語帳・記録はこのスマホの中（ブラウザの保存領域）にだけ置き、どこにも送りません。 Chrome の「サイトのデータを削除」をすると消えます。辞書は EJDict-hand（パブリックドメイン）。
