# paper_reader

英語論文の PDF を**章ごと**に分けて読み上げ、文中で引いた英単語を**単語帳**に貯めて **FSRS**（Anki と同じ方式）で復習するアプリ。

- **Mac 版**（このリポジトリの直下）: PDF の取り込み・貼り付けた英文の取り込み・章と文への分割・OCR・読み上げ音声づくり（macOS の `say`）・章の編集・辞書・単語帳・復習。
  しおり（続きから）・文の印（★）と Markdown への書き出し・本文の Fig. から図を開く・読み方の辞書・専門用語の一覧・取り出しの点検と AI（Claude Code）への手直しの依頼。ブラウザで使うローカルサーバー。
- **スマホ版**（`pwa/`）: Android の Chrome で動く PWA。Mac で作った論文・音声・単語帳を読み込み、オフラインで聞く・引く・復習する。
  → **https://rh-rep.github.io/paper_reader/** （GitHub Pages。使い方は app の「使い方」タブ）

論文・音声・単語帳・復習の記録は、使う人の Mac とスマホの中にだけ置きます。このリポジトリにもサーバーにも送りません。

## Mac 版

| ファイル | 役目 |
|---|---|
| `extract.py` | PDF → 題名・章・文（取り出し方 v3: 1段組みの判定、短冊に分けて描かれた行、斜体の小節、要旨の前の参考文献、Symbol の私用領域の文字、複合語のハイフン、上付き、参考文献は1件1文）。文字層が無いページは Tesseract で OCR。見出しはフォント（太字・本文より大きい）で見分け、OCR ページは「1 INTRODUCTION」型の番号で見分ける。貼り付けた英文は `build_from_text`（「## 見出し」「1. Introduction」、前が空行の短い行を見出しにする） |
| `store.py` | `data/papers/<sha8>/` への取り込み（元の PDF はコピーするだけ。貼り付けた英文は `original.txt`）・一覧・読み出し・章の編集（`edit_sections`: 段の上げ下げはその章と下の節だけ、分ける、前とつなぐ、名前。編集すると `manual` が付く） |
| `figures.py` | 図・表・数式の画像（版 2）。キャプション（Fig. / FIGURE / Table）から探し、その上（表は下）の画像・線・小さい字をまとめて 200dpi で切り抜く。罫線・横罫の表、右端に番号のある式も切り抜く。直しきれないものは AI の手直しで（`figures.json` の `manual`） |
| `quality.py` | 取り出した章と文の点検（章の並び・番号の飛び・文字の重なり・見えない文字・要旨に紛れた文献など）。重大なものがあれば画面で AI の手直しを勧める。`tools/check_paper.py` でも使う |
| `aifix.py` | 画面のボタンで、この Mac の Claude Code（`claude -p`）に手直し、または理解クイズ（`quiz.json`。決まりは `ai_fix_prompt.md`「理解クイズ」）づくりを頼む。その論文のフォルダの読み書きと app の Python だけを許し、pip・ネットは禁止。対話用の CLAUDE.md は読ませない（`--setting-sources local`）。1本ずつ |
| `state.py` | しおり（文の中身で覚える）と文の印・メモ（`state.sqlite`）。Mac とスマホで更新日時の新しいほうに合わせる |
| `pronounce.py` | 読み方の辞書。単位・上付き・ギリシャ文字は組み込みで直し（7 μm → 7 micrometers）、略語などは自分で登録。音声に渡す文だけに使う |
| `glossary.py` | 論文ごとの専門用語の一覧（辞書に無い語・略語と元の語・よく出る句）と端末内の訳。辞書に無い語はこれで引け、単語帳に登録できる |
| `audio.py` | `say` → WAV → `afconvert` で m4a（AAC）。1文ずつと、持ち出し用の章ごと・全体の1本もの。文ごとの音声は声・速さ・文を鍵に `audio/cache/` に控え、章を編集して番号がずれても同じ文は作り直さない |
| `translate.py` `tools/mac_translate.swift` | 文ごとの日本語訳（原文ごとの控え `translation_cache.json` で、同じ文は訳し直さない）。macOS 内蔵の翻訳（Translation フレームワーク、端末内で動き文は外に出ない）。初回に swiftc で `.bin/` に作る。英語・日本語の翻訳データはシステム設定 → 一般 → 言語と地域 →「翻訳言語…」で入れる |
| `lookup.py` | 単語を引く。EJDict → 活用を戻す → 派生語を戻す（近い語）→ Free Dictionary API（英英、ネット） |
| `vocab.py` | 単語帳（`vocab.sqlite`）。辞書で引いて「登録」した語を入れる。答えの記録（reviews）が復習の正本 |
| ディクテーション | 画面（Mac・スマホ）の「✎ ディクテーション」。文を聞いてランダムな空欄（Lv1〜5、Lv5 は全文）に打つ。空欄の選び方と判定は `assets/shared.js`（tokenize・pickBlanks・gradeWord・gradeSentence・levelAdvice） |
| `srs.py` | 復習の計算（py-fsrs、FSRS-6 の既定値、fuzz なし）。新しい語は1日20語まで。復習は「意味を思い出す」と「空欄を埋める」（例文の日本語訳を見て英文の空欄に単語を打つ。判定は `assets/shared.js`）の2つの出し方で、予定は共通 |
| `bundle.py` | スマホへ渡す zip と、スマホから戻る記録（JSON）の形 |
| `share.py` | 同じ Wi‑Fi のスマホへの一時的な受け渡しページ（合言葉付きのアドレス、10分で閉じる） |
| `ai_fix_prompt.md` `tools/check_paper.py` | AI に手直しを頼むときの決まった依頼文と、手直し後の確認コマンド。画面の「AI に手直しを頼む」で「フォルダの場所 ＋ 依頼文」をコピーできる。手直し済み（`sentences.json` の `manual`）は自動の取り出し直しで上書きしない。文が変わると音声・訳を作り直す（中身の目印 `items_hash`） |
| `server.py` | 画面と API を 127.0.0.1 で配る（標準ライブラリの `http.server`） |
| `index.html` `assets/` | 画面（読む・復習・スマホ）。`assets/shared.js` は図への参照・しおりの戻り先・単語の分け方をスマホ版と共有する（`pwa/js/shared.js` は同じ内容の写し）。「テキストを貼り付け」、「章を編集」（見出しの &lt; &gt;・名前・前とつなぐ、文の「ここで分ける」）、論文ごとの「図・表・数式」の一覧と、大きく開く表示 |
| `tools/` | 取り込み（`import_pdf.py`）、辞書づくり（`build_dict.py` `build_pwa_dict.py`）、架空のサンプル PDF（`make_sample_pdf.py`）、取り出し・図の切り抜きの点数（`eval_extract.py` `eval_figures.py`: 手直し済みの論文を正解として比べる） |

```sh
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp config.example.json config.json
.venv/bin/python tools/build_dict.py --config config.json      # 英和辞書（EJDict-hand、約4.4MB）を取ってくる
.venv/bin/python server.py --config config.json                # http://127.0.0.1:8796/
```

- 必要なもの: macOS（`say` と `afconvert`）、Python 3.11 以上。OCR を使うなら Tesseract（`brew install tesseract`）。
- データは `config.json` の `data_root`（既定 `data/`）に置く。

| ファイル | 役目 |

| `js/srs.js` | 復習の計算。py-fsrs の `review_card` を写したもの（Mac と同じ記録から同じ結果になる。`tests/test_pwa_parity.py`） |
| `js/lookup.js` | 単語を引く（Mac 版と同じ順）。辞書は `dict/<頭文字>.json` |
| `js/db.js` | IndexedDB への保存 |
| `js/zip.js` | Mac から来る zip（無圧縮）を読む |
| `sw.js` `manifest.webmanifest` `icons/` | オフライン動作とホーム画面への追加。画面とプログラムはつながれば必ず新しいものを取る（古いプログラムと新しい画面が混ざらないように） |

`pwa/dict/` は GitHub Actions（`.github/workflows/pages.yml`）が EJDict から作って Pages に載せます（リポジトリには入れない）。

### Mac とスマホの受け渡し

- **Mac → スマホ**: Mac の「スマホ」で論文を選び「Wi‑Fi でスマホに送る」→ スマホで QR を読んで zip を保存 → PWA の「データ」で読み込む。「ファイルで渡す」で zip を保存して Google Drive などで移してもよい。
- **スマホ → Mac**: PWA の「データ」→「記録を書き出す」→ 受け渡しページの「記録を Mac に送る」か、Mac の「記録ファイルを読み込む」。
- 復習の状態は保存せず、両方の答えの記録（uid 付き）を時刻順に計算し直して作る。同じ記録を何度読み込んでも二重にならない。

## 利用（clone して使う側）

この repo を clone したフォルダで使う。clone 側では直さず、開発側で直してコミットし、clone 側の `update.command`（`git pull --ff-only`）で取り込む（`data/` と `config.json` などの利用データは `.gitignore` で除外してあるので pull で消えない）。

- **技術スタック**: この節の下の「この app の技術スタック」。
- **正本: clone のフォルダの `data/`。**取り込んだ論文 PDF のコピー、章と文、音声、単語帳はここにしか無い。
- 起動: `start.command`。初回は `.venv` を作って pymupdf / pysbd を入れる（ネットが要る）。ブラウザで `http://127.0.0.1:8796/` が開く（使用中なら 8805 まで順に空きを探す）。
- 取り込み: 画面の「PDF を取り込む」か、画面へのドラッグ。元の PDF は**コピーするだけで動かさない**。同じ中身の PDF は2回取り込まれない。
  取り込むと裏で**読み上げ音声をまとめて作る**（10ページの論文で約1分40秒）。できるまではブラウザの読み上げで代わりに読む。
  画面を使わないなら `.venv/bin/python tools/import_pdf.py --config config.json <論文.pdf>`。
- **テキストを貼り付け**: 上の「テキストを貼り付け」→ 題名（空なら1行目）と英文を貼って「取り込む」。PDF と同じく章と文に分け、音声・訳を作る（スマホにも渡せる）。
  見出しになる行: 「## 見出し」「1. Introduction」「2.1 Methods」、前が空行の短い行（句点で終わらない）。元の PDF が無いので「AI に手直しを頼む」と図は出ない。
- **章を編集**: 論文の上の「章を編集」を押すと、見出しに <kbd>&lt;</kbd> <kbd>&gt;</kbd>（その章と下にぶら下がる節だけを1段上げる／下げる。3段まで）、「名前」、「前とつなぐ」（見出しを文に戻して前の章へ）、
  「文を見る」の各文に「ここで分ける」（その文から新しい章。短い文ならその文を見出しにできる）が出る。PDF の論文にも使える。
  編集すると `sentences.json` に手直しの印（`manual`、by: user）が付き、自動の取り出し直しで上書きされない。最初の編集の前は `sentences.orig.json` に残る。
  変わった文の分だけ音声と訳が作り直される（同じ文は控えから写す。作っている最中に続けて編集しても、最後の状態まで作る）。
- **続きから（しおり）**: 全体や章を聞いた位置を文ごとに覚え、「▶ 続きから（章・%）」で再開する。「最初から」で頭から。左の一覧の青い線が聞いた割合。
  文の中身で覚えるので、章の編集や AI の手直しで番号がずれても戻れる。1文だけの再生（文の ▶）ではしおりは動かない。スマホとも合う（新しいほう）。
- **文の印（★）**: 文の ☆ か、再生中に M キーで印。論文の上の「★ 印（n）」で一覧（押すとその文から再生、メモを書ける）。
  「Markdown をコピー／.md に保存」で、論文の中の順・章ごとに英文・訳・メモ・出典をまとめて書き出す（「全部の論文」も可）。
- **図への参照**: 本文の「Fig. 3」「Figures 2 and 4」「Table 1」「Eq. (3)」は押すと図が開く。再生中の文が図を指していれば、再生バーの横に小さく出る。
- **読み方の辞書**: 再生バーの「読み方の辞書」、または単語カードの「読み方を直す」。略語（DM → D M）などを登録すると、その語を含む文だけ音声が作り直される。
  単位・上付き・ギリシャ文字は組み込みで直す（7 μm → 7 micrometers、cm⁻² → centimeters to the minus 2、λ/14 → lambda over 14）。「試聴」で確かめられる。
- **専門用語**: 論文の上の「用語（n）」。辞書に無い語・略語（本文から元の語を探す: DM = deformable mirror）・よく出る句と、Mac 内蔵の翻訳の訳。
  本文では点線の付いた語。辞書に無い語はこの訳で引け、「登録」で単語帳に入る（最初に出てきた文が例文）。スマホでも引ける。
- **取り出しの点検と AI の手直し**: 取り込むと、章の並び・番号の飛び・文字の重なり・見えない文字・要旨に紛れた文献などを点検し、
  重大なものがあれば論文の上に「気になる所」と「この Mac の Claude Code に手直しを頼む」が出る。押すと claude -p が裏で PDF を見ながら直す
  （論文の文章は Claude に送られる。Claude Code の利用料がかかる。今回の試しで 9 ページの論文が約 2 分半・$1.1）。進み具合・費用・AI の報告が出る。
  claude に許すのはその論文のフォルダの読み書きとこの app の Python だけ（pip・ネットは使わせない）。
- **スマホの再生バー**: ボタンを大きくした。再生中に再生バーを上に引き上げる（上の細い線を押しても可）と、今の文とボタンが画面いっぱいになる。
  「押して翻訳を表示」でその文の訳が出る（次の文でまた隠れる）。下に引き下げるか戻るで元に戻る。
- **再生が止まったとき**: Mac は再生バーの下の「再生の記録」、スマホは「データ」の「再生の記録」に、止まった・飛んだ理由が残る
  （Android・機器が止めた、音声ファイルを読めなかった、再生を拒まれた、など）。音声を作り直し中の論文は、スマホに送ると音声が無く、
  ブラウザの読み上げになる（画面を消すと止まりやすい）ので、「スマホ」タブで知らせる。
- **理解クイズ**: 論文の上の「？ 理解クイズ」で、章ごとの4択（英語の問い・日本語の解説・根拠の文の ▶）。1〜4 キーで答え、Enter で次へ。
  クイズは AI が作る（AI の手直しで一緒に作るか、「理解クイズを作る（Claude Code）」でクイズだけ。論文1本で約2分・$0.7）。
  再生バーの「章の終わりにクイズ」をオンにすると、通しで聞いているとき章の最後の文のあとで止まってクイズが出る（答え終えたら「▶ 続きを聞く」）。スマホでも同じ。
- **ディクテーションの再生バーと、空欄ごとの答え合わせ**: 文の音声の位置を出すバー（動かすとその位置へ）と「−5秒・−2秒・⏯・+2秒」
  （Mac は ⌃← で −5秒、⌥⌘← → で ∓2秒、⌃Space で ⏯）。ブラウザの読み上げのときは位置を動かせないので出さない。
  空欄の横の ✓（Mac は ⌘Enter）でその空欄だけ ○△× が出る。全部確かめると結果が出る。「答え合わせ」は残りをまとめて確かめ、確かめ済みの空欄も数える。
- **ディクテーションから単語帳へ**: 文の中の見えている語は、押すと辞書のカード（「単語帳に登録」）。空欄の語は答え合わせが済むと押せ、
  横の「＋」1回で辞書を開かずに登録（その文が例文、登録済みは ✓、辞書にも用語集にも無い語は「辞書に無い」）。
  結果の欄の「外した語をまとめて単語帳に（n語）」で、△× の空欄の語をまとめて登録できる。
- **ディクテーションの続き**: 「文を見る」の各文の ✎、または再生中の文の ✎ で、その文からその章を順に練習する。「◀ 前の文／次の文 ▶」（Mac は Alt+← →）。
- **聞きながらディクテーション（スマホ）**: 再生バーを引き上げた画面の下の「✎ ディクテーション」を押すと、聞いている文の語の上に空欄の枠を被せる（文の幅・折り返しは変わらない。Lv1〜4、空欄はランダム）。文を読み終えると止まるので、打って「答え合わせ」→ ▶ で次の文、「もう一度」でその文をもう一度。外した語はまとめて単語帳へ。入/切と Lv は覚える。画面 ID は `pwa.player_full.dictation`。
- **図の拡大**: 大きく開いた図は、ホイール・ピンチ・ダブルクリック（スマホは2本指・ダブルタップ）で拡大し、ドラッグで動かせる（Mac は + − 0 キー）。
- 読み上げ: 章の ▶ でその章（節も含む）、「全体を読む」で最初から。スペースキーで一時停止／再開。再生速度は画面で変えられる（作り直し不要）。
  声は画面で選んで「この声で作り直す」。既定は `config.json` の `voice`（Ava (Premium)。入っていない Mac では Daniel → Samantha の順）と `rate`（175 語/分）。
- **スマホで聞く**: 「Finder で音声フォルダを開く」で `data/papers/<id>/export/` が開く。章ごとの `NN_<章>.m4a` と全体の `00_all.m4a`（AAC）を
  AirDrop（iPhone）や USB・クラウド（Android）で移す。章の横の「m4a」からも1本ずつ保存できる。メインのサーバーは LAN に出さない（出るのは下の受け渡しページだけ、10分間）。
- 単語: 「文を見る」を開くか、再生中に出る今の文で、単語をクリックすると辞書が出る。覚えたい語はカードの「単語帳に登録」で単語帳に入る（左下）。上の検索欄でも引ける。
  辞書は EJDict-hand（英和、CC0）。載っていない語は Free Dictionary API（英英、ネットが要る）を試し、それでも無ければ Weblio へのリンクだけ出す。
- **訳**: 取り込むと、文ごとの日本語訳を Mac 内蔵の翻訳（端末内。文は外に出ない）で作り、「文を見る」の各文の下に出す（「訳を表示」で切り替え）。
  初回は システム設定 → 一般 → 言語と地域 →「翻訳言語…」で「英語」と「日本語」をダウンロードしてから、論文の上の「訳を作り直す」。スマホに渡す zip にも入る。
- **AI に手直しを頼む**: 章分け・単語の区切り・文の切れ目・OCR がうまくいかない論文は、論文の上の「AI に手直しを頼む（プロンプトをコピー）」→「コピー」で、
  「論文のフォルダの場所 ＋ 決まった依頼文」を Claude Code などに貼る。AI は元の PDF を見て `sentences.json` を直し（前の版は `sentences.orig.json`）、
  `tools/check_paper.py` で確かめる。論文を開き直すと音声と訳が作り直される。手直し済みは自動の取り出し直しで上書きされない。
- **図・表・数式**: 論文の上の「図・表・数式（n）」で一覧。押すと大きく開く（← → で前後、Esc で閉じる）。「画像を新しいタブで開く」で PNG そのもの。
  自動では PDF に埋め込まれた画像だけを切り抜く。線で描かれた図・表・数式が抜けている、範囲や番号が違うときは「AI に手直しを頼む」で直す。スマホに渡す zip にも入る。
- **単語帳への登録は2段階**: 単語をクリック（調べる）→ カードの「単語帳に登録」。引いただけでは入らない。
- **再生**: 「文を見る」の各文の ▶ でその1文だけ。再生バーの −10 / −5 / +5 / +10 秒（← → キー、Shift で10秒）。
- **ディクテーション**: 論文の上の「✎ ディクテーション」（スマホは「図・表・数式」の横）。範囲（全体か章）と順番（順に／ランダム）を選ぶ。
  文の音声が鳴り、ランダムに空けた空欄に聞こえた語を打つ（Enter・Tab で次の空欄、最後で答え合わせ）。空欄は用語集などには頼らず毎回ランダム。
  レベル: Lv1 内容語から1語、Lv2 内容語の約2割、Lv3 約4割、Lv4 内容語すべて、Lv5 文全体を打つ（語の並びで突き合わせ、抜けた語も ×）。
  「もう一度」（⌘R）「ゆっくり（0.75 倍）」「押して訳を表示」。○ 一致／△ 1字違い・別の形／×。外した語は押すと辞書（単語帳に登録できる）。
  直近 20 文の正解率を出し、10 文たまってから 9 割超なら上げる・5 割未満なら下げる案内を出す（決めるのは人）。記録はその機器の中だけ。
- **空欄を埋める（復習のモード）**: 「復習」の見出しの横で「意味を思い出す／空欄を埋める」を切り替える（選んだほうを覚える。スマホも同じ）。
  単語を登録した文の日本語訳と、その単語を空欄にした英文（引用は外し、長い文は空欄の前後だけ）が出る。空欄に打って Enter で確かめる。
  活用形も正解、1字違いは「惜しい」。「ヒント（頭文字）」「わからない」もある。答えると、見出し語・意味と4つのボタンが出る（文は自動では読み上げない）。
  結果から勧める答え（間違い → もう一度、ヒント・惜しい → 難しい、正解 → 正解）が太枠になり、Enter でそのまま選べる（ほかも選べる）。
  復習の予定は「意味を思い出す」と共通。訳の無い例文は訳の代わりに意味を出し、空欄を作れる例文の無い語は「意味を思い出す」で出す。
- **復習**: 上の「復習」タブ。単語と引いた文が出る → 意味を思い出して「答えを見る」（スペース）→ もう一度／難しい／正解／簡単（1〜4）。
  ボタンの下が次に出るまでの間隔（FSRS）。新しい単語は1日20語まで。Z で1つ前の答えを取り消す。
- **Android**: 上の「スマホ」タブに手順と QR。スマホ版は https://rh-rep.github.io/paper_reader/（Chrome で開いて「ホーム画面に追加」）。
  「Wi‑Fi でスマホに送る」で同じ Wi‑Fi のスマホに論文・音声・単語帳を渡す（合言葉付きのアドレス、10分で閉じる。そのあいだだけ Mac が LAN で待つ）。
  スマホで復習した記録は、スマホの「記録を書き出す」→ 受け渡しページで送るか、ここで「記録ファイルを読み込む」。二重にはならない。
- OCR: 文字層の無いページは Tesseract（`/opt/homebrew/share/tessdata` の `eng`）で読む。どのページを OCR したかは画面の上に出る。

### この app の技術スタック

ここにはこの app での選び方と構成だけを書く。

| カテゴリ | この app で使っている技術 |
|---|---|
| Web・スマホ | 標準 `http.server` のローカルサーバ（127.0.0.1:8796）と素の HTML/JS、Range 配信、取り込み・作成・再生位置のプログレスバー、PWA（スマホ版）、無圧縮 zip と Wi‑Fi の受け渡し・QR、GitHub Pages での公開 |
| 音声・言語 | `say`（Ava (Premium)、無ければ Daniel → Samantha。175 語/分）→ m4a（AAC 64kbps）、読み方の辞書、Apple の端末内翻訳、EJDict の辞書引き、専門用語の一覧、PyMuPDF＋pysbd の章と文の取り出し（取り出し方 v3）、貼り付けた英文の章と文、Tesseract の OCR、図・表・数式の切り抜き（版 2） |
| データの扱い | FSRS の復習（Anki の作り、1日20語）、答えの記録を正本にした Mac ⇄ スマホの同期（しおり・印も）、py-fsrs を JS に写したスマホの計算、「AI に手直しを頼む」（claude -p で自動にも）、取り出しの点検、正解との比べで規則を直す、中身の目印で音声・訳を作り直す、中身で引く控え、画面での章の編集 |

#### 全体の形

```text
       取り込み（PDF・貼り付けた英文）                          GitHub（コードと架空サンプルだけ）
                 │                                        │ push → Actions が辞書を作って Pages に載せる
                 ▼                                        ▼
 Mac: ブラウザ画面 ⇄ Python ローカルサーバ（127.0.0.1:8796）      Android: PWA（Chrome、オフライン可）
      ・章と文に分ける（PyMuPDF / pysbd / Tesseract）             ・聞く・引く・登録・復習
      ・「AI に手直しを頼む」→ AI が sentences.json を直す        ・データは端末の IndexedDB だけ
      ・音声（say → m4a）・訳（Apple の端末内翻訳）                       ▲
      ・辞書（EJDict）・単語帳と復習（FSRS）                              │
                 │  zip（論文・音声・訳・各文の長さ・単語帳・答えの記録）──┘
                 │  ◀──── JSON（スマホで登録した語・答えの記録）
                 │  受け渡し: 同じ Wi‑Fi の一時ページ（合言葉付き・10分）か、ファイル
```

#### 選んだ理由（この app で決めたこと）

- 論文・音声・単語帳は Mac とスマホの中だけに置く（外部サービスに送らない）。英英辞書 API だけはネットがあるときの補助。
- 読み上げは機器によらず同じ声で鳴るよう、ブラウザの読み上げではなく音声ファイルにした。声は滑らかな Ava (Premium)（システム設定で追加する声）。入っていない Mac ではどの Mac にもある Daniel → Samantha の順に使う。
- 自動の取り出しで残る誤りは、ルールを増やしすぎず AI の手直しで埋める。
- スマホは PWA（ストア不要、GitHub Pages で配る）。復習の計算は Mac と完全に一致させるため、py-fsrs を写した。

#### 経緯（主な判断の変更、2026-09-24）

1. 読み上げ: Web Speech API → `say` の音声ファイル。声は一度 Samantha にしたが Daniel に戻した（2026-09-29 に既定を Ava (Premium) に変え、Daniel・Samantha は代わりの声にした）
2. スマホの復習計算: ts-fsrs → py-fsrs を写した自前の JS（学び直しで3日ずれたため）
3. Service Worker: 保存優先 → ネット優先（更新直後に新旧が混ざり、秒送りが効かず単語が自動登録されていた）
4. 取り出し方 v2: Applied Optics で章が分かれなかったのを直す（小さい太字の見出し、同じ行の切れ端、小さい要旨、字間の空白）
5. 単語帳: 引いたら自動登録 → 調べる → 登録の2段階
6. 「AI に手直しを頼む」を追加。2本の論文で AI が小節・式・謝辞の位置などを直した
7. 貼り付けた英文の取り込みと「章を編集」を追加。編集のたびに全部作り直さないよう、音声・訳を中身で引く控えにした
8. （2026-09-25）しおり・文の印・図への参照・読み方の辞書・専門用語を、新しい画面を作らず今の文の行・再生バー・単語カードに足した
9. 取り出し方 v3・図の切り抜き v2: AI が手直しした7本を正解にして点数を測りながら規則を足した（見出し F1 0.73→0.94、文 0.70→0.89、図の番号 0.50→0.87）
11. （2026-09-25）再生が勝手に止まる: 作り直しの最初に古い音声を消していたため、聞いている途中の画面が残りを次々に飛ばして「読み終わりました」になっていた。
    新しい音声がそろってから入れ替えるようにし、画面もファイルが取れないときは飛ばさずにブラウザの読み上げ・一時停止にした
10. 取り出しの点検で AI の手直しを勧め、ボタンで claude -p に頼めるようにした。試しで claude がユーザーの Python に pip で入れたので、pip とネットを禁止し、
    app の .venv が無いときはボタンを出さないようにした（入ったものは消した）

#### 残っている課題

- Android の実機では試していない（スマホ画面の大きさと公開ページの Service Worker は確認）
- 番号も太字も無い見出しは自動では見つけられない（AI の手直しで補う。点検で「長い章」と出る）
- 読み方の組み込みの直しと、専門用語の抜き出しは、耳・目で全部は確かめていない（say が上付きなどをどう読むかは直したあとの文で確認）
- 「この Mac の Claude Code に手直しを頼む」は試しで1本（9ページ）だけ通した
- 数式が独自の書体の論文は式が化ける（読み上げでは AI 手直しで (equation) に）
- PDF 自体に文字が無い箇所は取り出せない（DeMi の `he M1 mirror`）
- 英英辞書の API は作業環境からつながらず未確認
